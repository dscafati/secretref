# 0010. Apache-2.0 license

Status: Accepted

Date: 2026-10-20

## Context

secretref is a developer tool that companies will want to adopt. Adopters need a clear license with a patent grant, and contributors need to know their contributions carry the same terms.

## Decision

We license secretref under Apache-2.0. Contributions are accepted under the same license.

## Consequences

- Companies can use, modify, and redistribute secretref, with a patent grant.
- Derivative works must keep the license notice and state changes.
- Dependencies must be compatible with Apache-2.0.
